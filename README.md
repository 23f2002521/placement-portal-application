# placement-portal-application

A web-based Placement Portal developed using Flask, Jinja2, Bootstrap, and SQLite to streamline campus recruitment processes for institutes. The system provides role-based access for Admins, Companies, and Students, enabling efficient management of company registrations, placement drives, student applications, and recruitment outcomes.

The application ensures a structured placement workflow through company and drive approval mechanisms, application tracking, status management, and placement history maintenance. It also prevents duplicate applications, supports profile management, and offers centralized access to recruitment data for all stakeholders.

### Key Features
- Role-based authentication and authorization
- Company registration and approval workflow
- Placement drive creation and approval system
- Student profile and resume management
- Application tracking and status updates
- Duplicate application prevention
- Student and company search functionality
- Administrative dashboard with placement statistics
- Complete placement and application history records

### Tech Stack
- **Backend:** Flask
- **Frontend:** HTML, CSS, Bootstrap, Jinja2
- **Database:** SQLite

This project was developed as an academic web application focused on digitizing and simplifying campus placement management.
